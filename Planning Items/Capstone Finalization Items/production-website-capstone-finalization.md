# Final Deliverable: Production Website Capstone

Submit your production-quality HTML/CSS capstone website and the evidence package that demonstrates your planning, implementation, testing, remediation, and release decisions.

## Published site: live URL or instructor-approved preview URL.


## Repository: organized files, meaningful final state, and clear README or release notes.


## Production website: complete approved page scope using semantic HTML and modern CSS, without JavaScript-dependent core requirements.


## Planning evidence: planning package, content architecture, responsive wireframes/annotations, and acceptance criteria.


## Build evidence: CSS architecture, responsive layout, media/typography, accessibility, and discoverability evidence from Modules 2-6.


## Release evidence: validation, broken-link checks, responsive regression checks, accessibility spot checks, performance diagnostic, compatibility notes, and known limitations.


## Technical defense: concise written or recorded explanation of what you built, why it fits the audience/task, what you tested, what you fixed, and what remains limited.


## AI disclosure: document meaningful AI use, what you accepted/rejected, and how you verified final work.
