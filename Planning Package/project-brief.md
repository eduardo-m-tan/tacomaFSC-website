# Project Brief

## Site Purpose
The purpose of this website is to provide information that figure skaters would be searching for while not being overlapped with all the other info on the main rink website.

## Primary Audience
The audience will be prospective figure skaters and/or their parents in the area looking to learn more about getting themselves or their kids into figure skating or to continue learning figure skating at this club.

## Primary User Tasks

1. Learn about club directors and coaches
2. Learn about upcoming in- and out-of-house events
3. Learn about group classes
4. Find session schedules
5. Contact staff or board

## Constraints
Not all functions that would be useful for this page are in the scope of this or previous classes. Photos need to be attained with proper licensing. 

## HTML/CSS Scope
This will be a six-page public information site for a local figure skating club, giving information on their classes, schedules, coaches, events, and visiting/contact page. Common CSS will be used for proper formatting and good user design/experience, small animations and accessibility functions will be added in as well. JavaScript subject to be added in later.
