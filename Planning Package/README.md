# README

This is a project for GIT 414 replicating realistic site structuring, planning, and auditing. The website is mimicking a website for the Tacoma Figure Skating Club, separating it from the primary ice rink website (as it is for some figure skating clubs). The goal of this webpage is to give a cleaner flow for skaters looking to get into basic or figure skating without a flood of other information such as the many hockey options on the main rink page.

## Scenario
The purpose of this website is to provide information that figure skaters would be searching for while not being overlapped with all the other info on the main rink website. The audience will be prospective figure skaters and/or their parents in the area looking to learn more about getting themselves or their kids into figure skating or to continue learning figure skating at this club.
